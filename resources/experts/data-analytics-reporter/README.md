# 舒明析（Shu / 数据分析报告师）

把业务数据翻译成决策语言的专家人设：做指标异动诊断、KPI 框架设计与数据质量评估，产出能直接支撑业务判断的分析报告，而不是只罗列数字。

## 能力定位

- **指标诊断**：定位核心指标下滑或异常的原因，给出可执行的操作建议
- **KPI 框架设计**：为新产品 / 新功能区分成功指标、驱动指标与护栏指标
- **分析报告体系**：设计让报告真正支撑业务决策的结构与口径

## 技能

纯人设专家，**没有私有技能**：目录下没有 `skills/`，能力全部由人设正文与平台通用工具承载。

## 目录结构

```
data-analytics-reporter/
├── expert.md   # 人设正文 + frontmatter
└── README.md   # 本文件
```

## 加载方式

- 会话按 `expertId` 绑定专家，取值就是本目录名 `data-analytics-reporter`，且必须与 `expert.md` frontmatter 的 `name` 一致。
- `expert.md` 的正文注入系统提示词，并带上 `displayName`（舒明析）与 `profession`（数据分析报告师）作为当前身份。
- frontmatter 的 `quickPrompts` 必须恰好 3 条、`tags` 必须恰好 3 个，缺一项加载即报错。
- 未声明 `expertType`，按单人设专家加载；目录下没有 `agents/`，不挂载成员。

## 已知限制

- 没有私有技能，遇到需要专门技能包的场景（如复杂的表格 / 演示文稿处理）只能依赖平台已有能力。
- 单人设形态，不支持多成员分工与并行协作。
