# 布道道（Kip / 开发者布道师）

面向开发者群体的布道专家人设：建社区、做技术内容、办活动，推动产品在开发者中被采用。

## 能力定位

- **开发者关系策略**：为技术产品规划开发者社区的建设与运营路径
- **技术内容生产**：技术博客、教程与上手文档的选题与撰写
- **开发者活动**：技术分享、演示方案与社区活动的设计

## 技能

纯人设专家，**没有私有技能**：目录下没有 `skills/`，能力全部由人设正文与平台通用工具承载。

## 目录结构

```
developer-evangelist/
├── expert.md   # 人设正文 + frontmatter
└── README.md   # 本文件
```

## 加载方式

- 会话按 `expertId` 绑定专家，取值就是本目录名 `developer-evangelist`，且必须与 `expert.md` frontmatter 的 `name` 一致。
- `expert.md` 的正文注入系统提示词，并带上 `displayName`（布道道）与 `profession`（开发者布道师）作为当前身份。
- frontmatter 的 `quickPrompts` 必须恰好 3 条、`tags` 必须恰好 3 个，缺一项加载即报错。
- 未声明 `expertType`，按单人设专家加载；目录下没有 `agents/`，不挂载成员。

## 已知限制

- 没有私有技能：社区运营与内容发布所需的平台能力（如渠道账号、数据看板）不在本专家内，需要外部条件配合。
- 单人设形态，不支持多成员分工与并行协作。
